🌴 Palmprint widget — script-tag demo

One <script> tag, no bundler, no React in the host page. Mounts a floating verify button at the configured corner and fires palmprint:verified on the window when it passes. The event contains a signed session token when data-api-base points at your Palmprint server routes.

Floating button

The button at the bottom-right of this page is mounted by the script tag below. Open DevTools — there is no Palmprint markup in the page source. 

<script
  src="/dist/palmprint-widget.js"
  data-position="bottom-right"
  data-theme="emerald"
  data-shape="pill"
  data-size="md"
  data-level="medium"
  data-mode="both"
  data-num-tests="2"
  data-capture-mode="off"
  data-challenge-style="standard"
  data-api-base="/api/palmprint"
  data-label="Verify with Palmprint"
  defer
></script>

Inline mount via data-target

Or mount into a specific element by passing a CSS selector. The button below was rendered into #inline-slot.

Sign-up form gate: 
<script src="/dist/palmprint-widget.js"
        data-target="#inline-slot"
        data-shape="rounded"
        data-theme="dark"
        data-size="sm"
        data-challenge-style="handedness"
        defer></script>
